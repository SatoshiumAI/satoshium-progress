  • Onboarding Mentor — a guided “start here” flow for first-time visitors (Jun • when ready)
  • Protocol / Architecture Guide — plain-English map of how Satoshium works (Jul • when ready)
  • Claim Verifier (Trust Labels) — labels answers as Verified / Likely / Speculative / Unknown (Aug–Sept • when ready)

Canon remains the truth-source. One unified Satoshium AI can operate through multiple internal modes — tools are released publicly only when they improve clarity and understanding.
