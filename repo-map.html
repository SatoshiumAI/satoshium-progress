🧭 Repository Map

Satoshium Repo Map

A simple view of the core repositories and what each one exists to do.

📜 Canon (Constitutional Truth)

  • satoshium-canon — the constitutional truth layer (definitions, doctrine, claims)
  • satoshium-specs — structured specs (agents, models, lifecycle, meta standards)

Canon is slow. Canon is deliberate. Canon is the source-of-truth.

🛡️ Trust Layer (Governed Execution)

  • satoshium-trust — trust primitives (proof, verification, governance patterns)
  • satoshium-safety — safety doctrine + guardrails (Aegis, rules, constraints)
  • satoshium-registry — agent identity + registry patterns (future)

Trust is the bridge between “intelligence” and “safe intelligence.”

🤖 Core Agents (Aligned Builders)

  • satoshium-core — shared logic + utilities for agents
  • satoshium-curator — canon-aware curation + structured updates
  • satoshium-agent-lab — sandbox for testing multiple agent architectures

Agents are created only when useful — not for volume.

🌐 Public Build Layer (Live)

  • Satoshium-Progress — primary public gateway (roadmap, changelog, demos, and core explainer pages)
  • Satoshium Labs (Emerging) — experimental “future experience” environment built through small interactive Bitcoin + AI simulations (Holodeck-style)
  • Bitcoin 101 — glossary + fundamentals + security guides (expanded over time)
  • Demos — small tools shared when ready (not rushed)

Satoshium-Progress will gradually expand into a full public learning and experimentation environment. Satoshium Labs will live within this layer as the interactive “future experience” space — clearly labeled Experimental while it matures.

🎬 Media & Storytelling (Ongoing)

  • YouTube releases — narrative + visual storytelling to make the future understandable
  • Essays — long-form thinking for doctrine, philosophy, and public clarity
  • Visual artifacts — diagrams, concept maps, and future-world interfaces

Satoshium isn’t just built — it is explained.

Built in public. No hype. Visible progress only.
